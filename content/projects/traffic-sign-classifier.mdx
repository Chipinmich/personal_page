## The Goal

Build a small convolutional network that classifies road-sign photographs, and
understand every part of the pipeline rather than treating the model as a black
box.

## Why This Project

Image classification is the standard first computer-vision project for a reason:
the problem is easy to state, the failure modes are visible, and the data is
messy enough to be interesting. Signs photographed in the real world come with
motion blur, glare, partial occlusion and bad angles, all of which punish a model
that has only learned clean examples.

## Approach

1. Assemble and inspect the dataset before writing any model code.
2. Establish a trivial baseline so there is something to beat.
3. Train a small CNN and track validation accuracy per class, not just overall.
4. Look at the confusion matrix and go find the examples the model gets wrong.
5. Add augmentation only where the errors suggest it will help.
